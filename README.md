# LucidAccuracy website

Marketing site for LucidAccuracy: Global Workforce, Technology & Business Solutions.
Static site built with [Astro](https://astro.build); no server or database is needed.

## Commands

```bash
npm install
```

```bash
npm run dev
```

```bash
npm run build
```

`npm run build` writes the finished site to `dist/`, which can be hosted on any static host.

## Where things live

- `src/data/site.ts` holds all content: contact details, office addresses, markets, solutions, industries, AI Calling Agent copy, demo call scripts and case studies. Edit text here.
- `src/pages/` holds one file per page. `src/pages/solutions/[slug].astro` renders the five solution pages.
- `src/components/` holds shared parts: header, footer, 3D globe, world map, call demo.
- `src/scripts/main.ts` holds all behaviour: smooth scrolling, globe, call demo, navigation, contact form. `src/scripts/effects.ts` holds the connecting-dots network, count-up numbers and scroll progress bar.
- Motion deliberately keeps running when the visitor's OS has "reduce motion" switched on; only entrance travel is shortened.
- Day/night mode: `src/styles/global.css` (`:root[data-theme="dark"]` tokens) and `initTheme` in `src/scripts/main.ts`. First visit follows the device setting; the toggle choice is remembered.
- Explainer videos: `public/video/<id>.mp4` and `.jpg` posters, made by `node scripts/video/render.mjs` from `scripts/video/studio.html` + `studio.js`; music is synthesised by `scripts/video/music.py` (no third-party licence). Edit `src/data/videos.ts` for titles.
- Industry photos: `public/images/industries/`, credits in `src/data/photos.json` (shown on `/credits/`). `scripts/import-photos.mjs` adds more from Wikimedia Commons.
- `public/audio/calls/` holds the voice clips for the demo calls, named `<scenario>-<line>.mp3`. A call is shown only when all of its lines have clips; the Real Estate call still needs lines 0, 4 and 5.
- `Dockerfile` and `Caddyfile` build the site and serve it (used by Railway).
- `public/og/` and the favicons are generated by `npm run generate:og` (needs Playwright with Chromium).

## Before launch

- Replace the case studies in `src/data/site.ts` with verified, approved projects.
- Add the two remaining U.S. addresses to `locations` in `src/data/site.ts` (the brief lists five; three are in).
- Connect the contact form to a form service or CRM. It currently opens the visitor's email app with the message filled in.
- Have legal review `src/pages/privacy.astro` and `src/pages/terms.astro`.
- Add social profile links to `site.social` in `src/data/site.ts`.

## Contact form

`server/index.mjs` serves the built site and receives the form at `POST /api/contact`. Every submission is written to the server log, appended to `$DATA_DIR/submissions.jsonl` (a Railway volume mounted at `/data`), and emailed to `NOTIFY_TO` once SMTP is configured.

Railway variables:

- `DATA_DIR=/data`, `NOTIFY_TO=Info@lucidaccuracy.com`
- `SMTP_HOST=smtp.hostinger.com`, `SMTP_PORT=465`, `SMTP_USER=Info@lucidaccuracy.com`
- `SMTP_PASS` — the mailbox password, set by the owner in the Railway dashboard (never commit it).

`GET /api/health` reports whether email and storage are active. Run locally with `npm run build && npm start`.
